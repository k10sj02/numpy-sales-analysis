# NumPy Sales Analysis

A simple Python project that uses **NumPy** to analyze monthly sales data — calculating total, average, highest, and lowest sales across the year.

## 🧮 Features
- Calculates:
  - Total yearly sales
  - Average monthly sales
  - Highest and lowest monthly sales
- Identifies the best-performing month
- Demonstrates core NumPy operations for beginners

## 📂 Project Structure

numpy-sales-analysis/
│
├── num.py             # Main script for sales analysis
└── README.md

## 🚀 How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/k10sj02/numpy-sales-analysis.git
   cd numpy-sales-analysis

2. Make sure you have Python installed (3.8+ recommended).

3. Run the script:

   ```bash
   python num.py
   ```
